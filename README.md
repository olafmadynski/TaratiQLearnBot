To run:

Main Game:

- Navigate to root folder and run: npm install once and then npm start

Q-Learning bot:

- Download Q-Table from here: https://drive.google.com/file/d/12wvwuL8dwjilNBq-4xLn650lOh48oGFF/view?usp=sharing

- Place in the same folder as ai_server.py

- Run in cmd 'python ai_server.py'



To test performance of Q-Table:

- Run 'python python_tarati.py', configured to run 20k games against a random bot, 10k as white, 10k as black.
